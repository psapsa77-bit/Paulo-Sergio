# 📱 COMO USAR - Guia para Iniciantes

## ⚡ Modo SUPER FÁCIL (3 cliques)

### Passo 1: Baixar o Projeto
1. Clique no botão verde **"Code"** no topo da página do GitHub
2. Clique em **"Download ZIP"**
3. Extraia (descompacte) o arquivo ZIP em uma pasta no seu computador

### Passo 2: Instalar (AUTOMÁTICO)

**Se você usa Windows:**
- Dê um duplo clique no arquivo: `INSTALAR_WINDOWS.bat`
- Espere a instalação terminar (pode demorar alguns minutos)

**Se você usa Mac ou Linux:**
- Dê um duplo clique no arquivo: `instalar.sh`
- Se não funcionar, abra o Terminal, vá até a pasta e digite: `bash instalar.sh`

### Passo 3: Abrir o Programa
- Dê um duplo clique no arquivo: `ABRIR_PROGRAMA.bat` (Windows) ou `abrir.sh` (Mac/Linux)
- Uma janela do navegador vai abrir automaticamente!

---

## 🎯 Como Usar o Programa (na tela do navegador)

### Opção 1: Preencher Formulário (MAIS FÁCIL)

1. Na tela que abrir, você verá duas opções na lateral esquerda
2. Escolha: **"Formulário Manual"**
3. Preencha os dados:
   - **Nome do funcionário**
   - **CPF**
   - **Cargo**
   - **Data de admissão** (quando entrou na empresa)
   - **Data de demissão** (quando saiu)
   - **Salário bruto** (quanto ganhava)
   - **Tipo de rescisão** (escolha na lista)
   - **Valores das verbas** (saldo de salário, férias, 13º, FGTS, etc.)
   - **Descontos** (INSS, Imposto de Renda)

4. Clique no botão azul: **"🔍 Analisar Rescisão"**

5. Pronto! Você verá:
   - ✅ Todos os dados organizados
   - 📊 Gráficos coloridos
   - 💰 Quanto vai receber (valor líquido)
   - 📄 Explicação de cada valor

6. Para salvar/enviar ao cliente:
   - Role a página até o final
   - Clique em **"📑 Baixar Relatório PDF"** para ter um arquivo bonito
   - O arquivo vai para a pasta "Downloads" do seu computador

### Opção 2: Usar Arquivo JSON (precisa já ter um arquivo pronto)

1. Na lateral esquerda, escolha: **"Upload de Arquivo JSON"**
2. Clique em **"Browse files"** (Procurar arquivos)
3. Selecione seu arquivo .json
4. Pronto! A análise aparece na tela
5. Clique em **"📑 Baixar Relatório PDF"** para salvar

## 💡 DICA: Baixe um Exemplo Primeiro

Se é sua primeira vez:

1. Na tela do programa, escolha **"Upload de Arquivo JSON"**
2. Clique no botão: **"📥 Baixar Exemplo JSON"**
3. Um arquivo vai para sua pasta "Downloads"
4. Abra esse arquivo com o Bloco de Notas (Windows) ou TextEdit (Mac)
5. Você pode editar os valores e salvar
6. Depois faça upload desse arquivo editado

## ❓ Problemas Comuns

### "Não achei o Python"
- Não se preocupe! O script de instalação instala tudo automaticamente
- Só execute o arquivo INSTALAR (passo 2 acima)

### "O programa não abre"
- Verifique se a instalação terminou sem erros
- Tente fechar tudo e abrir novamente o arquivo ABRIR_PROGRAMA

### "Erro ao gerar PDF"
- Tente primeiro gerar o HTML (botão "📄 Baixar Relatório HTML")
- O HTML você já consegue abrir no navegador e imprimir como PDF

### "Não sei o que colocar nos campos"
- Use os valores que estão na rescisão trabalhista (documento da empresa)
- Se tiver dúvida, deixe em 0.00 (zero)
- O programa vai calcular e mostrar o que você preencheu
